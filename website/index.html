Legal

Privacy

How Sieu-Sv_Library handles account, script and security data.

Current service status

The website is read-only. Google sign-in is available only to create or access an account session and to record acceptance of the current Terms and Privacy Policy. Community profiles, uploads, profile edits, votes and report submissions remain disabled. Existing community database records have not been deleted; the paused community API does not serve them. Public scripts from the GitHub repository remain available.

Data stored before the pause

The application database can contain a Google account identifier, username, display name, avatar URL, bio, public profile identifier, account timestamps, username-change history, community script source and metadata, version snapshots, vote records, report details and per-account rate-limit counters. Reports are not public profile content.

Google sign-in

Google OAuth is used to verify the account. The application receives the stable Google account identifier, verified email status, display name and profile-photo URL. The verified email is used temporarily to generate a default username; the full email address is not stored in the application database. The stable Google account identifier is stored to recognise the account. Google processes OAuth requests under its own privacy terms.

When a person completes sign-in, the application stores the Google account identifier, account fields shown above, and a consent receipt containing the accepted Terms version, Privacy Policy version and acceptance time. The receipt is used to record which texts were accepted. The application does not intentionally store the Google access token.

Cookies and technical data

The sign-in flow uses a Secure, HttpOnly, SameSite=Lax session cookie with a seven-day lifetime, plus short-lived OAuth state and signed consent cookies that expire after ten minutes. Cloudflare may process connection and request metadata to deliver and protect the site. Cloudflare Turnstile is not used for the read-only sign-in flow.

Public information

Before the pause, usernames, display names, avatars, bios and public community scripts could be displayed to visitors. The pause hides community profiles and community scripts from the website, but it does not erase records already stored. Files in the public GitHub repository remain public and are governed by the repository license and applicable third-party licenses.

Service providers and international processing

The service uses Cloudflare Workers and D1, Google OAuth and GitHub-hosted repository content. These providers may process information in locations outside Viet Nam under their own terms. The actual data locations and the applicable cross-border-transfer requirements have not yet been verified provider by provider.

Retention and requests

A complete fixed retention schedule and self-service account export or deletion flow are not currently implemented. Existing application records remain stored until an appropriate retention and deletion process is established. For a privacy request, do not post personal information in a public GitHub issue; ask the repository maintainer for a private contact route first.

About

Sieu-Sv_Library

A read-only catalog for discovering scripts and projects from GitHub.

Project

Sieu-Sv_Library is the web catalog connected to the SieuSV-Storage repository. Visitors can browse curated repository scripts and inspect their source code. Community accounts, public profiles, uploads, votes and reports are temporarily disabled while legal, privacy and security requirements are reviewed.

The repository is maintained at minhReal/SieuSV-Storage. Contributions can be proposed through a GitHub Pull Request.

Credits

Project credits and plugin information are documented in the repository README and LICENSE.

Community

Rules

Keep the library useful and safe for everyone.

  1. Only publish content you created or are allowed to redistribute.
  2. Do not upload malware, credential theft, hidden data collection or destructive scripts.
  3. Do not impersonate another creator or misrepresent ownership.
  4. Do not include private information, passwords, tokens or personal contact details in public scripts or profiles.
  5. Do not spam uploads, votes, comments or other service endpoints.
  6. Do not use the library to harass people, evade platform safeguards or violate applicable laws or platform rules.
  7. Review scripts before running them. The source library does not guarantee that community submissions are trustworthy.

Content that breaks these rules may be hidden or removed.
